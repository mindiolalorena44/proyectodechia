# Chía Mora — Delicia de Chía

Sitio web en HTML para presentar el emprendimiento **Delicia de Chía** y sus productos.

## Archivo principal

- `index.html`: página web completa. Incluye estilos CSS y el contenido de la página.

## Cómo abrir

Abre `index.html` en un navegador web (Chrome, Firefox, Edge, etc.).

## Publicación

Para publicar el sitio, sube `index.html` a un servicio de alojamiento web estático. Si el HTML utiliza recursos externos, necesitarás conexión a internet para cargarlos.

## Nota

El archivo original se conservó sin modificar su contenido.
